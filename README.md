# Stock options strategy evidence dashboard

Team-facing decision dashboard for the NSE five-minute cash-stock strategy and the proposed Dhan Data API subscription.

## Decision

Do not begin a recurring subscription based on the current evidence. The recent validation sample lost 16.60%, produced a 0.28 profit factor, and was unprofitable across every tested symbol. A one-month research purchase is reasonable only if existing data sources cannot complete a multi-year validation.

## Evidence included

- `data/summary.json`: headline performance metrics generated by the backtester.
- `data/data_quality.json`: sample coverage and OHLCV validation counts.
- `data/trades.csv`: complete 409-trade audit ledger.
- `data/equity.csv`: realized equity ledger.
- `data/report.md`: original generated backtest report.
- `METHODOLOGY.md`: rules, assumptions, accuracy limits, and decision gates.

Dashboard values are copied from these source artifacts. Rounded display values are used only for presentation; source files retain the generated precision.

## Run locally

No build step or external dependency is required. Open `index.html`, or run:

```bash
npx serve .
```

## Deploy to Vercel

Import this repository into Vercel and accept the defaults. The root directory is the repository root and the project is a static site.
